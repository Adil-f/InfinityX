# License Proposal — MIT

## Recommendation

Apply the **MIT License** to:

- `Adil-f/InfinityX`
- `Adil-f/AutoVendita`
- `Adil-f/Adil-f` (optional; profile READMEs often omit a license)

## Why MIT

- Simple and widely understood by recruiters and contributors
- Permissive: others can reuse with attribution
- Appropriate for portfolio / demo / learning projects
- Does not imply warranty or production readiness

## What will be added (only after your OK)

A root `LICENSE` file containing the standard MIT text with:

```text

```

## What will NOT happen automatically

- No license file will be committed until you reply with approval, for example:
  - `Approvo MIT su InfinityX e AutoVendita`
  - or `Approvo MIT solo su AutoVendita`

## Alternatives (if you prefer)

| License | When to choose |
| --- | --- |
| MIT | Default for open portfolio projects |
| Apache-2.0 | If you want explicit patent language |
| GPL-3.0 | If you want copyleft / derivative works must stay open |
| Unlicense / CC0 | If you want maximally public domain-like dedication |
| No license | All rights reserved; others cannot legally reuse |
