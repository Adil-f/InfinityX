# Website Builder

Composition: category → layout family → brand system → sections → pages.

Anti-clone: 6 structurally different layout families. Diversity checks ensure same-category sites are not logo/color-only variants when section order/brand rotation applies.

Forms: `data-submit="disabled"` by default.

SEO: title, description, canonical, OG, sitemap.xml, robots.txt.

Export: ZIP via `zip` CLI to `data/exports/`.
