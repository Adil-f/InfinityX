# InfinityX - Modern Technology Website

A complete, modern, and interactive website for InfinityX, featuring beautiful UI design, smooth animations, and advanced functionality.

## 🌟 Features

### Design & UI
- **Modern Gradient Design**: Beautiful gradient backgrounds and text effects
- **Responsive Layout**: Fully responsive design that works on all devices
- **Smooth Animations**: CSS animations and JavaScript-powered interactions
- **Interactive Elements**: Hover effects, click animations, and visual feedback
- **Professional Typography**: Clean and modern font choices with proper hierarchy

### Sections
1. **Hero Section**: Eye-catching landing area with animated elements
2. **About Section**: Company information with animated statistics
3. **Services Section**: 6 comprehensive service offerings with icons
4. **Portfolio Section**: Filterable project showcase
5. **Contact Section**: Contact form with validation and company info
6. **Footer**: Social links, quick navigation, and newsletter signup

### Interactive Features
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Portfolio Filtering**: Filter projects by category (Web, Mobile, Design)
- **Contact Form**: Form validation and success notifications
- **Scroll Animations**: Elements animate as they come into view
- **Statistics Counter**: Animated counters for company statistics
- **Smooth Scrolling**: Smooth navigation between sections
- **Progress Bar**: Visual scroll progress indicator
- **Typing Effect**: Animated text typing in hero section
- **Parallax Effects**: Subtle parallax scrolling effects
- **Notification System**: Success/error notifications for user feedback

### Technical Features
- **Performance Optimized**: Fast loading with optimized assets
- **SEO Friendly**: Proper meta tags and semantic HTML
- **Accessibility**: Keyboard navigation and screen reader support
- **Cross-browser Compatible**: Works on all modern browsers
- **Mobile First**: Designed with mobile devices in mind

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Local web server (optional, for development)

### Installation
1. Download or clone the project files
2. Open `index.html` in your web browser
3. For development, use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

### File Structure
```
web/
├── index.html          # Main HTML file
├── styles.css          # CSS styles and animations
├── script.js           # JavaScript functionality
└── README.md           # This documentation
```
